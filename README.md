A 38-second vertical Short cut from Windah Basudara's GTA VI gameplay: Jason reels in a fish on the jetty and holds it up while Windah reacts, facecam and gameplay in split screen, with a make.fun pitch outro telling viewers they can make money on make.fun by making clips with AI.

Watch it: https://www.youtube.com/shorts/rVrTd9FzLHk

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `VIDEO.json` (the video's address) to `out/VIDEO.json`, where the grader reads it. The video itself is the entry.
